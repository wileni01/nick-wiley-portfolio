I used to describe myself as a data scientist who wrote code. Over time, more of my work moved into the parts I used to hand off, such as getting an application running, connecting it to real data, and debugging permissions or deployment issues.

A coding assistant helped when I got stuck. I could paste an error, ask what it meant, and get a few concrete checks to run. The suggestions still needed testing, but having a place to start made it easier to keep going.

These days I try to build one path I can run before adding features. When I use an assistant, I give it a narrow task, read the changes, and test the behavior myself. That helps me understand the code I’ll have to maintain.
