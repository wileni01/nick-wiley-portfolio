A coding assistant makes it easy to start three fixes while I’m still trying to finish the first one. I’ve had better luck writing down what should work when I’m done and keeping the conversation tied to that outcome.

I try to get a change running locally early so I can see what it does. If the conversation wanders, I start a fresh one with the current state, the next step, and what I’ve already checked. A clean handoff is often quicker than explaining a long chain of false starts.

I also stop after each change to read the diff and run the relevant tests. Otherwise, several small requests can turn into one large change whose behavior I can no longer account for.
