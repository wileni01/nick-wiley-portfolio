## Getting the story into the game

I put the Lantern Compact story into the campaign and worked through how missions load their dialogue and pick up after a save. I swapped in new ship sprites, port art, and interface graphics, then checked how they looked in the game.

## Playing through the same thing twice

I wanted to be able to run the same playtest twice and see what changed. I had Claude Code help with a test driver that sends input through SDL the same way the player’s controls reach the game. That gave me a way to repeat menu, campaign, and save checks. I used Codex to check that the game loaded the new mission text and that the other mission fields stayed intact.

I used CMake to build the Windows version and checked the packaged game against the files I’d staged.
