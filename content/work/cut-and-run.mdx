## Connecting content to the game

The new story had to work inside the campaign, where players could pick up a mission, see the right dialogue, and return to it after a save. I integrated the Lantern Compact storyline into the mission and dialogue pipeline. I updated ship sprites, port artwork, and interface graphics, and checked how the game loaded and displayed the replacements.

## Testing campaign flows

I used C and SDL for the Windows runtime and CMake to build it. I wrote a scripted playtest runner that exercised the game through its own controls and produced repeatable runs for checking menu navigation, campaign actions, and saves. I packaged the Windows build with its assets and checked the archive against the staged files.

## How I used coding assistants

I asked Claude Code to add a scripted test driver that used the game’s regular SDL input path. I used Codex to check that the Windows build loaded the updated mission text and that the other mission fields stayed intact.
