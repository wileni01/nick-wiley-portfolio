## Recovering the original game in Ghidra

I started with the compiled 32-bit executable. In Ghidra, I worked through the disassembly and the decompiler’s C-like output. I followed calls from the map, sailing, and port screens, gave routines names as their roles became clear, and mapped the data they shared for ships, routes, and game state.

That gave me enough context to reimplement behavior in C and compare it with the original. For example, I checked how a ship changed heading and advanced along a route, then used focused tests to catch differences as I rebuilt more of the game.

## Moving to 64-bit Windows

I rebuilt the game as a native 64-bit Windows application, with SDL handling the window, input, and audio. I treated the original save format separately from the new in-memory data structures so existing saves could still be read. Recorded play and regression tests helped me check that campaign state and controls behaved as expected after the port.

## Publishing the patch

The free beta fixes crashes and freezes, including problems around loading saves and returning from encounters. The installer patches a separate copy of the game. Players need their own copy of the English CD release, since the download contains no original game data. The beta has been played on 64-bit Windows 11. The patch site has the supported version, setup instructions, and known issues.

## How I used coding assistants

I set up a Codex-assisted Windows test pass around the patch’s release requirements: check the archive hashes, use a separate game copy, and record any launch or save issues.
