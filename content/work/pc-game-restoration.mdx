## Recovering the original game in Ghidra

I wanted to get through a campaign without the game freezing or crashing. I opened the original 32-bit executable in Ghidra and followed the code behind the map, sailing, and port screens. As I figured out what each piece did, I named the routines and tracked how they shared data about ships, routes, and game state.

I rebuilt pieces in C and compared them with what the original did. For instance, I watched how a ship turned and followed a route, then wrote tests to catch differences as I went.

## Moving to 64-bit Windows

I rebuilt the game for 64-bit Windows and used SDL for the window, controls, and sound. I handled the old save format separately so the new build could still open existing saves. I used recordings and repeatable tests to check how the controls and campaign behaved after the port.

## Publishing the patch

I used Codex to help put together the Windows tests for the release. I wanted to check the archive hashes, use a separate game copy, and record any trouble launching or loading a save.

The free beta fixes crashes and freezes, including some that happened when loading a save or returning from an encounter. You’ll need your own copy of the English CD release. The installer patches a separate copy and uses the game’s original art and sound. You can find setup instructions and known issues on the patch site.
