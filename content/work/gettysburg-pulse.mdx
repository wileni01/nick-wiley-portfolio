## Finding a tour or planning a day

I wanted to be able to compare tours by things like price and length, see what’s on that weekend, and check for park notices before heading out. I built GettysburgTours.com to bring all of that together. Listings show where the info came from and when it was last checked. If you find a tour you like, you can go straight to the operator to book.

## Fixing the event calendar

A change to the Majestic Theater’s site broke my calendar import. I ended up with wrong showtimes and duplicate listings. I used Codex to help update the parser and add tests for both problems. I checked the listings against the theater’s published schedule before putting them back up, which brought back 51 performances and cleared out duplicates and unverified entries.

The importer now matches events by source page and showtime. If it can’t read a schedule, it keeps the last published listings and logs what went wrong. I also added a shared cache so the public pages can reuse results between visits.
