## Preserving the factory software

I started by documenting the system and making a record of the original files I could back up. On the vehicle, I copied six selected files to my laptop. Two reads matched byte for byte, and I recorded which files were still missing.

## Prototyping changes

I built an offline interface prototype and tested a read-only backup package against simulated inputs. I’m using that work to prepare for a fuller backup and a tested return to the factory software before trying interface or performance changes on the unit. The revised interface has been tested off the car. In-vehicle validation and a full restore are still open.
