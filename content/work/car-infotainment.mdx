## From power-on to driving controls

I wrote custom software for the car’s QNX-based infotainment unit and installed it in the vehicle. The portrait screen opens with a short animation and a photo of Chief, then hands off to the driving controls.

## Preserving the factory software

I reverse-engineered the original infotainment binary to understand how the factory software starts and which files it relies on. That work informed the new interface and helped me identify what to back up. I copied a set of factory files from the car and verified that the backup copies matched. I also tested a read-only backup package with simulated inputs. The verification covered the factory files I copied from the unit.

## How I used coding assistants

I used Codex to add automated tests for the backup and file comparison tools. Those tests used simulated inputs. I verified the recovered files separately using copies from the infotainment unit.
