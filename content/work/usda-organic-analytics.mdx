The team brought Salesforce, program records, and U.S. Customs and Border Protection import data into one AWS warehouse. That let analysts compare certification and import records in the same reporting workflow.

I built a text classifier with scikit-learn to map inconsistent import descriptions to the program’s reporting categories. I also worked on Tableau reports, documented metric definitions and data limitations, and ran training and office hours for analysts using the new reports.
