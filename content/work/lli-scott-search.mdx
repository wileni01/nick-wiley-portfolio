The tool prioritized records using signals such as bounced email and time since last engagement. It used Apollo.io to propose updates, then showed reviewers the current and suggested values side by side.

I built the review interface in Flask, with keyboard shortcuts, an undo action, and a progress counter. Approved changes synced back to HubSpot, and the tool kept a history of the review decisions.
