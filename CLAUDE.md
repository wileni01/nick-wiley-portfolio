# nick-wiley-portfolio

Next.js portfolio for Nicholas A. Wiley at https://www.nickwiley.ai. Vercel deploys the GitHub repository’s `main` branch to production.

Use Node 24 and npm. Run `npm run build` and `npm run lint` before pushing. See the README for content and résumé PDF generation.

Use concrete language and credit collaborators when appropriate. Say what was built, what changed, and what has been verified. The game and car projects use generic names and illustrations. Keep identifying details out of public copy and assets.
