Gettysburg Battlefield TouriOS (SwiftUI + Mapbox + CarPlay) · Android (Compose + Android Auto) · Fastify backend

How it works

  • Driving and walking tour with turn-by-turn navigation to each stop
  • Proximity-triggered narration: audio starts when you arrive, not when you tap
  • Interactive overlays: troop positions, lines of advance, period maps
  • Driver-safe surfaces: CarPlay and Android Auto show only large controls
  • Shared data model in shared/ (TypeScript interfaces + JSON schemas) used by all three clients
  • Offline-first tour packages; the backend serves tour versions and updates

Status: in development, August 2026.
