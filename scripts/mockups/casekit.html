README.md
# CaseKit Workspace

Six independent, local-first consulting
extensions in one portable directory.
Copy this folder to any machine, open it
in a coding agent (Claude Code, Codex,
Devin) and say "please set up".

you: please set up
     → scripts/setup.sh installs each
       extension in its own environment and
       proves it: compatibility test + every
       product's test suite

you: build me a workplan from these notes
     → case-planner
you: turn this finding into slides
     → slidesmith
you: what drove the margin decline?
     → case-analyst

## The family

Case Planner    dependency-aware workplans,
                deterministic rescheduling,
                formula-driven Excel views
SlideSmith      accurate, editable consulting
                PowerPoint, evidence-cited
Case Analyst    case-style answers; auditable
                Excel models and dashboards
Case Architect  evidence-verified architecture
                intelligence, pinned-commit
                citations, ATO support
Case Steward    provenance-grounded case memory:
                sources, decisions, actions,
                risks, validated briefs
CaseKit         family spec, CasePack v1
                interchange, schemas, fixtures

Extensions exchange context only through
explicit files (CasePacks), never imports.
Offline mode installs entirely from a
wheelhouse: no network at all.
Validator output is real (captured 2026-08-23). Agent session illustrative.
